# what-did-you-eat-today
A C++ program to input user daily calorie intake

## Aim
This program aims to integrate an AI with a console application to avoid the hassle of having to input the calories intake manually.

## Stages

### Stage 1
Simple console input, logging to a log file and on console output . 

### Stage 2 
integrate AI as middle agent to parse input and create a structured / tabulated format
